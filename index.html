💡 คำแนะนำสำหรับการติดตั้ง:

คุณครูสามารถนำหน้านี้ไปวางเป็น "หน้าหลักโรงเรียน (Home / Portal)" ใน Google Sites เพื่อให้นักเรียน ผู้ปกครอง และครูเข้ามาติดตามข่าวสาร ดูปฏิทิน และตรวจสอบรายชื่อนักเรียนได้ตลอดเวลา

ขั้นตอนการติดตั้งใน Google Sites:

  1. เปิด sites.google.com และเข้าไปที่ไซต์ของโรงเรียน
  2. ที่แถบด้านขวา เลือกเมนู "แทรก (Insert)" > "ฝัง (Embed)"
  3. เลือกแท็บ "ฝังโค้ด (Embed code)" แล้ววางโค้ดที่คัดลอกด้านบน หรือเลือกแท็บ "ตาม URL (By URL)" หากนำไฟล์ขึ้น GitHub Pages / Netlify
  4. ลากปรับขยายความกว้างกล่องให้เต็มหน้าจอ และกด "เผยแพร่ (Publish)"
